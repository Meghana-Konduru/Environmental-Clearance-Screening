
# Project Data

This directory contains the regulatory corpus and sample project
inputs used by the Environmental Clearance Pre-Screening Service.

## Structure

### regulations/

Contains official environmental clearance documents:

- EIA Notification 2006
- Schedule and General Conditions
- Relevant amendments
- Relevant Office Memoranda

### sample_projects/

Contains sample project inputs used to test:

- Project information validation
- Regulatory document retrieval
- Environmental screening workflows
- Mandatory national park proximity scenario

## Data Integrity

- Original regulatory PDFs must remain unchanged.
- Source URLs and document metadata must be maintained.
- Sample projects must be clearly identified as test data.
- No sample result should be presented as an actual government
  environmental clearance decision.
